# Radar

Фінансові новини з обраних видань: збирає стрічки й сторінки сайтів, відбирає новини за темами,
перекладає іноземні заголовки українською, об'єднує повтори й позначає те, що самі видання
подають як головне. Працює без штучного інтелекту.

**Сторінка новин:** https://goloborodko-yaroslav.github.io/radar/ (оновлюється щогодини)

## Як це працює

Щогодини GitHub запускає Radar (`.github/workflows/radar.yml`), той збирає новини й публікує
сторінку на GitHub Pages. Комп'ютер для цього вмикати не треба.

## Як змінити видання, теми чи параметри

Усе лежить у теці [`config/radar`](config/radar):

| Файл | Що в ньому |
|---|---|
| `topics.txt` | теми й ключові слова, згруповані в розділи `[Назва групи]` |
| `sources.json` | видання: адреси стрічок, режим «усі новини», ознаки головних новин |
| `settings.json` | скільки днів показувати, чи шукати в першому абзаці тощо |

Відкрийте файл на GitHub, натисніть олівець (Edit), змініть і збережіть (Commit changes).
Оновлення запуститься одразу, нова сторінка з'явиться за кілька хвилин.

Як записувати ключові слова — на початку `topics.txt`.

## Оновити вручну

Вкладка **Actions** → **Radar** → **Run workflow**.

## Версія для Linux

Тека [`radar`](radar) — повна програма для Linux Mint з вікном налаштувань, сповіщеннями
й розкладом. Встановлення: `sh radar/install.sh`. Докладніше — [`radar/README.md`](radar/README.md).
