# Radar

Збирає фінансові новини з обраних видань, відбирає їх за вашими темами, перекладає
іноземні заголовки українською й показує список на сторінці в браузері. Працює за
розкладом (за замовчуванням щогодини) і надсилає сповіщення на робочий стіл.

Потрібен лише Python 3 і GTK, які вже є в Linux Mint. Додатково нічого встановлювати не треба.

## Як користуватися

- **Меню → Radar** відкриває вікно з вкладками «Новини», «Видання», «Теми», «Розклад і параметри».
- Правий клік по Radar у меню дає «Відкрити список новин» і «Оновити новини зараз».
- Сповіщення має кнопку **«Відкрити»**, яка відкриває список новин у браузері. Вимкнути
  сповіщення про свіжі новини можна у вкладці «Розклад і параметри»: новини й далі оновлюватимуться
  на сторінці. Ранковий підсумок вмикається там само, окремо.

На сторінці новин смужкою зліва позначено ті, яких ви ще не бачили. Угорі є пошук і
фільтр за виданнями. Якщо навести мишку на перекладений заголовок, з'явиться оригінал.

## Сторінка новин

- **Стрічка** — усі новини за часом. Якщо про одну подію пишуть кілька видань, вона показується
  одним рядком із посиланнями «також: …». Головною стає найраніша публікація; пізніші передруки інших видань показуються як «також».
- **Важливе** — новини, які саме видання подає як головні: Мінфін, Forbes, Економічна правда і LIGA
  виділяють їх на своїх сторінках; NYT, BBC і FT ставлять на головну сторінку; dev.ua позначає
  «Гаряченьке»; будь-яке видання — позначкою «Терміново» / «Breaking» у заголовку.
  У сповіщеннях важливі новини йдуть першими й позначені ★.
- **За темами** — ті самі новини, розкладені за групами тем.
- ✕ ховає новину, а «Сховати прочитані» прибирає вже відкриті. Ці позначки зберігає браузер.

## Дашборд

Кнопка «Дашборд ↗» на сторінці новин, кнопка «Дашборд» у вікні, правий клік по Radar у меню
або `radar dashboard`. Оновлюється разом із новинами.

- **Гривня**: долар і євро — офіційний курс НБУ з графіком і рекордом, міжбанк, середній курс у банках,
  готівковий ринок і різниця між ринком та НБУ.
- **Національний банк**: облікова ставка, міжнародні резерви.
- **Світові ринки**: індекси, нафта, золото, акції з графіками за 4 місяці.
- **Криптовалюта**: ціни, зміна за добу й тиждень, капіталізація ринку.

Склад інструментів — у файлі `~/.config/radar/dashboard.json`. Джерела: НБУ, Мінфін, CNBC, CoinGecko.

## Ранковий підсумок

Щодня о 09:00 (час змінюється в налаштуваннях) приходить одне сповіщення з головним за ніч:
спершу важливі (★), далі ті, про які пишуть найбільше видань. Звичайне оновлення в цей час мовчить,
щоб не було двох сповіщень одночасно.

## Команди в терміналі

```
radar run                         оновити зараз
radar open                        відкрити список новин
radar sources                     список видань
radar source add URL [Назва]      додати видання (RSS знайдеться сам)
radar source remove НОМЕР|НАЗВА   видалити видання
radar source off|on НОМЕР         вимкнути / увімкнути видання
radar topics                      список тем
radar topic add "Тема: ключ1, ключ2"
radar topic remove "Тема"
radar schedule 60                 кожні 60 хв (або 30, 2год…)
radar schedule 08:00 13:00 19:00  у визначений час
radar schedule off                лише вручну
radar notifications off|on        вимкнути / увімкнути сповіщення про свіжі новини
radar digest                      ранковий підсумок зараз
radar source all НОМЕР            усі новини видання без фільтра (ще раз — вимкнути)
radar dashboard                   відкрити дашборд
radar status                      стан і останній запуск
```

## Теми і ключові слова

Файл `~/.config/radar/topics.txt`, одна тема на рядок: `Назва: ключ1, ключ2`.

| Ключ | Що знаходить |
|---|---|
| `кредит` | початок слова: «кредити», «кредитування», «кредитний» |
| `облікова ставка` | фразу в будь-якій формі: «облікову ставку», «обліковій ставці» |
| `=євро` | лише точне слово, без «Європа» |
| `банк & кібер` | обидва слова в одному заголовку |
| `[Назва групи]` | група тем (розділ у вкладці «За темами») |

## Де що лежить

| | |
|---|---|
| Налаштування (видання, теми, розклад) | `~/.config/radar/` |
| Сторінка новин, база, журнал | `~/.local/share/radar/` |
| Програма | `~/.local/share/radar/app/` |
| Розклад (таймер systemd) | `~/.config/systemd/user/radar.timer` |

## Особливості джерел

- **Мінфін і Forbes** не мають RSS, тому Radar читає їхні сторінки. Точного часу публікації
  там немає, тож показується час, коли Radar побачив новину.
- **НВ**: розділ biz.nv.ua блокує автоматичні запити. Radar бере загальну стрічку НВ і залишає
  лише новини з biz.nv.ua.
- **Bloomberg**: офіційні RSS-стрічки розділів Markets, Economics, Crypto, Industries.
- **Reuters** закрив RSS і блокує автоматичний доступ, тому заголовки Reuters беруться
  через пошук Google News (`site:reuters.com`). Посилання ведуть на статті Reuters через Google News.
- Переклад виконує безкоштовний сервіс Google Translate. Надсилаються лише заголовки новин.

## Видалення

```
~/.local/share/radar/app/uninstall.sh          # видання й теми залишаться
~/.local/share/radar/app/uninstall.sh --all    # видалити все
```
